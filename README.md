# 💙 Energy Orb AR

<p align="center">
An interactive AI-powered hand tracking experience built with JavaScript and MediaPipe Hands.
</p>

---

## ✨ Overview

Energy Orb AR is an interactive web application that creates a dynamic glowing energy orb which responds to real-time hand movements.

Using MediaPipe Hands, the project tracks hand landmarks and generates visual effects including particles, glow, and motion to create an immersive experience directly in the browser.
